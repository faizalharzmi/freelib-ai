# UI design system

FreeLib AI uses a friendly visual language: Nunito, a `#f7f8ff` canvas, violet `#6d28d9` primary actions, emerald/mint accents, slate text, radial violet and mint backgrounds, rounded white cards, strong heading weights and generous spacing. Django templates and plain CSS implement the interface. The FreeLib AI name and book-focused copy remain distinct.

The CSS has desktop, tablet (950px) and mobile (650px) breakpoints. Forms have visible labels, focus rings and disabled submit/loading text. Error, partial-provider and empty states are visible in the results template. Django Admin keeps its native interface.
